# IKR Website

Marketing site voor [IKnowRight](https://ikr-website.vercel.app) — TikTok-bureau voor food brands.

**Stack:** Next.js 16, React 19, Tailwind 4, GSAP. Geen CMS.

Live: [ikr-website.vercel.app](https://ikr-website.vercel.app). `iknowright.be` is nog WordPress en bewust niet gekoppeld.

## Repo

- `ikr-website/` — de app. Vercel root directory.
- `design/` — Figma-exports, niet deployed.
- `big_idea.md`, `progress.md`, `decisions.md`, `next_session.md`, `blockers.md` — werksessies, geen productdocs.

## Setup

```bash
cd ikr-website
```

Daarna: [ikr-website/README.md](ikr-website/README.md).

Push naar `master` deployt automatisch naar Vercel (Hobby).
